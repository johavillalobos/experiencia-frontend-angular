# Refactorización de Frontend - Sistema de Gestión de Rifas

Este repositorio documenta mi experiencia como Desarrolladora Frontend Freelance en un sistema de gestión de rifas que se encuentra actualmente en producción. 

Nota: El código fuente de este proyecto es propiedad del cliente y no puede ser publicado por acuerdos de confidencialidad. Sin embargo, aquí detallo mi rol, las tecnologías aplicadas y los resultados obtenidos.

## Mi Rol en el Proyecto

Trabajé en conjunto con otro ingeniero (quien gestionaba el backend y el despliegue). Mis responsabilidades principales fueron:

- Refactorizar vistas y componentes existentes utilizando Angular y SCSS.
- Mejorar la experiencia de usuario (UX) y la interfaz (UI) en múltiples pantallas del sistema.
- Optimizar la estructura de los estilos para facilitar el mantenimiento del código a futuro.
- Coordinar y entregar los cambios al ingeniero encargado para su validación y subida a producción.

## Tecnologías Utilizadas

- Angular (Framework de frontend)
- TypeScript
- **SCSS** (Preprocesador de estilos)
- **HTML5 / CSS3**
- **Git / GitHub** (Control de versiones y trabajo colaborativo)
